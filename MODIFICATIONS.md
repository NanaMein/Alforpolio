## Alforpolio v2 (This Repository)

Base: [TryGhost/Source](https://github.com/TryGhost/Source) v1.7.5

This is the modern, actively maintained version of Alforpolio. It uses Source as its foundation (rather than Solo) to take advantage of the latest Ghost theme features and structure.

### What Changed From Source

- Theme name, branding, and repository metadata updated to Alforpolio
- Package metadata adjusted (name, description, demo URL, repository)
- README rewritten for the Alforpolio project
- Additional Handlebars partials added (e.g., lightbox, search toggle, typography font options)
- Extended theme settings (font selection, header styles, navigation layouts)
- Social icon partials added for X, Mastodon, Bluesky, TikTok, Threads, and others
- JavaScript modules added for lightbox, pagination, and dropdown behaviour

### Roadmap

- Built-in light/dark mode toggle (carried over from legacy Alforpolio v1)
- Additional post/page layout options
- Podcast and news/update module support

## Legacy Alforpolio (v1)

Base: [TryGhost/Solo](https://github.com/TryGhost/Solo)

The original Alforpolio was built on the Solo theme. That codebase is preserved for reference but is no longer actively developed. Key features from v1:

- Built-in light/night mode toggle (dark mode)
- Extended theme settings and customisation options
- Portfolio and technical-writer focused layouts
